> PixelBrat pisao:
> int *ptr;
> *ptr = 42; <-- ovde pada
Klasična greška! Deklarisao si pointer ali nisi mu dodelio adresu. Pointer pokazuje na random memoriju i crashuješ sistem.

Treba ovako:

  int vrednost;
  int *ptr = &vrednost;  /* & daje adresu */
  *ptr = 42;            /* sada radi! */

Ili koristiti malloc() za dinamičku memoriju. Čitaj Kernighan & Ritchie, strana 94.

> h4ck3r_ns pisao dobar odgovor
Tačno! Dodao bih još — uvek proveri da li malloc() vratio NULL pre korišćenja:

  int *ptr = malloc(sizeof(int));
  if (ptr == NULL) { printf("Nema mem!\n"); return; }
  *ptr = 42;
  free(ptr);  /* UVEK oslobodi! */

Memory leak je GORI od crash-a na produkciji. Svakako, pogledaj sekciju FAJLOVI — postavio sam K&R knjigu u PDF formatu za preuzimanje.
